ARCHIVE PRINCIPLES

収集から保存までを、
一つの流れとして記録する。

01

CATALOG

国、通貨、額面、発行年、シリーズ、状態、参考資料を統一形式で整理します。

02

PROVENANCE

入手経路と来歴を収蔵品に結び付け、情報の根拠と更新履歴を保持します。

03

LOCATION

バインダー、ページ、ポケット単位で物理的な所在を管理します。

04

PRESERVATION

台帳と画像を分離し、NAS上で世代バックアップできる構成を採用します。

SYSTEM BOUNDARY

外部公開と個人台帳を分離。

  1. PUBLIC公式概要

    GitHub Pagesには説明と匿名サンプルのみを配置。

  2. PRIVATEアプリ本体

    運用コードと設定は非公開リポジトリで管理。

  3. LOCAL収蔵データ

    台帳、画像、価格、保管位置は私設NAS内だけに保存。
