# 歴史地図の紙幣・国家系譜

## 基本方針

収蔵品は `data/collection.json` へ追加するだけで完了としない。発行年、発行主体、当時の国家・体制、通貨期、地図上で示す領域を確認し、`app.js` の `historicalAtlas` へも反映する。

ここでいう「系統国」は、過去の政権や占領体制を現在の国家と法的に同一視する語ではない。同じ地域の紙幣史を年代順に比較するための表示上のまとまりを指す。占領地券は占領国の国内通貨へ統合せず、原則として使用地域の後続期へ接続する。地図も占領・実効支配域の資料がない限り、対象地域の外郭を `outline-only` で示し、支配域であるかのように塗らない。

## 新規登録時の確認項目

1. 収蔵品の最初の4桁年を代表年として扱えるか確認し、年代範囲や再加刷年を混同しない。
2. `era` と利用可能な最寄りの `mapYear` を決め、年が異なる場合は `mapLegend` に差を明記する。
3. CShapesの `NAME` と一致する `featureNames` を確認する。個別境界がない場合は `focusCoordinates` による位置表示を使う。
4. 占領・傀儡政権・軍政下の券は、領域資料がなければ `territoryMode: "outline-only"` とし、`mapControl` と `detail` で政治状態を説明する。
5. 前後期を比較すべき場合は共通の `currencyFamily`、一意の `currencyKey`、年代順の `currencyOrder` を設定する。
6. 地図の年代、地域、国家・体制から対象を選べること、系譜を切り替えられること、収蔵台帳へ到達できることをブラウザで確認する。
