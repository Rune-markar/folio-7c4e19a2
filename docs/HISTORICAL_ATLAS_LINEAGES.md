# 歴史地図の紙幣・国家系譜

## 基本方針

収蔵品は `data/collection.json` へ追加するだけで完了としない。発行年、発行主体、当時の国家・体制、通貨期、地図上で示す領域を確認し、`app.js` の `historicalAtlas` へも反映する。

ここでいう「系統国」は、過去の政権や占領体制を現在の国家と法的に同一視する語ではない。同じ地域の紙幣史を年代順に比較するための表示上のまとまりを指す。占領地券は占領国の国内通貨へ統合せず、原則として使用地域の後続期へ接続する。地図も占領・実効支配域の資料がない限り、対象地域の外郭を `outline-only` で示し、支配域であるかのように塗らない。

## 2026-08-14 全体監査の判断記録

- `ar-5-late-peso` は収録画像の券面、額面、イグアスの滝の意匠を根拠に、10ペソ・アルヘンティーノ P#313へ訂正し、IDも `ar-10-1983-peso-argentino` へ変更した。
- `de-1-1940` は券面の発行根拠と発行機関名を根拠に、一般のライヒスマルク銀行券ではなくReichskreditkassenschein P#R136へ訂正した。一般ライヒスマルク期とは別の地図期・収蔵スコープに置く。
- 厳密な収蔵スコープへの移行で地図期がなかった旧ボリバル3件、ブラジル3件、オーストリア・クローネ1件について、対応する通貨期を追加した。既存期へ年代や通貨の異なる紙幣を便宜的に混ぜない。
- 1914年比較期へ便宜的に入っていたデンマーク1936年券・1972年系列券を、それぞれ独立した地図期へ分離した。
- 年代不明だったトルコ500リラ券は、イスタンブール大学正門の意匠と中央銀行資料からE6の1971–1974年発行・P#190と確定し、1983年E7期から分離した。
- 旧管理表由来12件に共通していた `202211130` はカタログ番号ではない不要データとして破棄し、今後も扱わない。

## 新規登録時の確認項目

1. 収蔵品の最初の4桁年を代表年として扱えるか確認し、年代範囲や再加刷年を混同しない。
2. `era` と利用可能な最寄りの `mapYear` を決め、年が異なる場合は `mapLegend` に差を明記する。
3. CShapesの `NAME` と一致する `featureNames` を確認する。個別境界がない場合は `focusCoordinates` による位置表示を使う。
4. 占領・傀儡政権・軍政下の券は、領域資料がなければ `territoryMode: "outline-only"` とし、`mapControl` と `detail` で政治状態を説明する。
5. 前後期を比較すべき場合は共通の `currencyFamily`、一意の `currencyKey`、年代順の `currencyOrder` を設定する。
6. 国・地図期には長方形の国旗SVGを必ず設定する。個別の歴史旗は `flag`、共通スプライトは国別割当を使い、内容を説明する `flagAlt` と適用年代を示す `flagPeriod` を記録する。「03 国名・通貨」で全ての旗が同じ長方形の枠内に表示されることをブラウザで確認する。
7. 地図の「01 年代 → 02 地域 → 03 国名・通貨」から対象を選べること、系譜を切り替えられること、当該通貨期だけの収蔵台帳へ到達できることをブラウザで確認する。件数は `atlasCollectionScopes` の明示IDだけを数え、0件の比較用期はボタンを無効化する。
8. `node scripts/audit.mjs` を実行し、追加した地図期・国旗・収蔵スコープを含む全体監査を通す。

### 国旗表示の移行方針

2026-08-15に代替文字の移行例外を廃止した。歴史旗SVGがある地図期はそれを優先し、それ以外は共通SVGスプライトの国別シンボルを表示する。OS依存の絵文字旗は使わず、未設定の国を監査で検出する。
